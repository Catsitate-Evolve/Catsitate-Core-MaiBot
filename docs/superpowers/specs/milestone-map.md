## M3 表达四项交付明细(spec §3.8,v0.8.0)

1. **说说发布**:bot 自主决定发说说(工具 `qzone_post(reply_reference, reply_style?)` 两段式,正文由表达生成层产出,场景 prompt v4 说明用法)✅
2. **日记**:入睡任务旁路 LLM 生成→发布 API 深夜直发→醒来后延迟回注 ✅
3. **回注**:bot 自己的说说以 self 消息注入虚拟流(qzone_post 即时回注/日记延迟回注)✅
4. **真实聊天见闻注入**:当日「空间见闻」摘要优先,无见闻回退「近期刷到」叙事列表 ✅
