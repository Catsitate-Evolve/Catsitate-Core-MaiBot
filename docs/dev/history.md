# 里程碑时间线

> 依据 `CHANGELOG.md` 与 git 历史整理。三个阶段:一期/二期打基础(8 月中),三期 QQ 空间三步走(8 月底),随后工具驱动化、表达层、终审修复与正式版收官(9 月初)。开发迭代不单独立版本,以下 8 月底~9 月初的过程按主题与日期记述,统一归入 v1.0.0。

## v0.1.0(2026-08-15)一期:人格基础设施

联调验收通过的第一个完整版本,奠定「注入 + 旁路 LLM」两大骨架:

- **注入框架**:环境/备忘/好感度块前插 system 之后(缓存友好分层注入);等级规则按等级单条注入好感度块最前(省 token 且提升缓存命中)。
- **好感度**:批次结算制(提前结算+日终兜底顺延)、LLM 判定结合 bot 人设、delta 上限可配置、5 级规则独立配置、bot 发言识别。
- **备忘录**:双通道(工具+命令)、单条 TTL、注入当前流+说话人两维度。
- **贴表情**:内置 30 项精选 QQ 表情表 + 每流冷却,仅群聊可用。
- **戳一戳**:主动戳工具(仅冷却限制)。
- **reply 上下文补传**(规则层)+ **LLM 哨兵层**(可选,默认关)。
- **图片重看工具**(VLM)。
- **时间感知**:节日/节气/天气环境块。
- **旁路 LLM**:经主程序 task 名路由,各能力独立模型+独立超时;4 个模板接入主程序「提示词管理」页统一编辑。
- 细节:旁路调用记账(llm_usage)+每日告警阈值;60s 后台调度器;92+ 单元测试。

## v0.2.0(2026-08-15)二期:拟人作息

- **好感度自然衰减**:LLM 判定拟人化衰减(未互动 N 天,0~-decay_max),群聊 quote/@ 防误判。
- **睡眠管理**:睡眠=日程窗口(LLM 自主作息)、绝对静默拦截、晚安判定入睡、睡醒回顾报告。
- **日程**:入睡时生成次日动态活动日程(1 睡眠+1~8 活动)、日程块注入、日程窗口 trigger 主动发言(表达权交主程序)、update_schedule 工具。
- **主动私聊问候**(挚友级)、**备忘提醒时间 remind_at**(日程收录+无日程兜底注入)。
- 旁路模板新增 4 个(decay/sleep_confirm/schedule_generate/sleep_review)。

## v0.3.x(2026-08-16 ~ 08-18)按人重构 + 公测修复

- **v0.3.0(8/16)按人重构**:好感度按人唯一标识跨流聚合;「特别」等级全表独占(最多 1 人,占位钳制 99 分);主动问候统一为「特别+私聊」;公测前最终审查修复一批(负分钳制/日程恢复/日志 PII 防护/权限收紧等)。
- **v0.3.1(8/18)公测修复集**:睡眠窗口语义对齐(静默开/关两种入睡方式);跨午夜睡眠窗口保留;7 个 `*_timeout_ms` 默认 None→0(修 tomlkit 序列化崩溃);RPC 帧超限修复(取消息不带二进制);GPL-3.0 许可证。
- **v0.3.2(8/18)旁路模板自动部署**:插件加载时把 `prompt_templates/catsitate_*.prompt` 自动同步到主程序 `prompts/zh-CN/`——主程序 `load_prompts()` 在插件启动后调用,同次启动即生效,无需手动复制/重启;WebUI 编辑产物写 custom_prompts,插件优先读取。

### 表达与修正(9/2)

- **表达**:`qzone_post` 工具+表达润色层(「说什么」归 planner,「怎么说」归润色);日程窗口 `read_qzone`/`send_qzone` 分离+发布主动触发(含冷启动种子自举);说说发布 tid 三处登记;**日记**(入睡 LLM 生成、深夜直发、醒来回注);**空间见闻**(窗口结束摘要注入真实聊天);**点赞通知源C**;通知独立于浏览窗口;`view_friend_feeds` 全域查看工具;`inspect_image` image_hash 路径。
- **联调改进**:三动作工具全域化(白名单只管非 qzone_* 工具);通知不再强制触发(走自然概率);日记模板照搬 diary_plugin 蓝本+全天聊天记录(message.get_by_time 全局取数);`clip_text` 截断统一尾加"..."。
- **配置固化与日志收敛**:虚拟伪群号固化为常量(不可配置);润色模型默认 replyer;日记删除超长硬上限;润色不再截断;回注/登记存全文;业务错误回执带限制语义(-10049「先歇一歇别重试」)。
