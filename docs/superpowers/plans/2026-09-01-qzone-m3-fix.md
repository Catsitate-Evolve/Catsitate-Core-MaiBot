> 所有文档/prompt/注释自包含——面向零上下文开发者/LLM，不引用开发历史。

## 修正六项

### Task 1: 消息格式重构（结构化标签 + quote 引用）

**改动**：
- `messages.py` `build_feed_message`：浏览动态改「作者：/内容：/[]参数行」三行格式
- `plugin.py` 通知正文构造：加「→ 用quote引用原说说」说明
- `plugin.py` `_qzone_pump` 通知项注入：reply 段引用原说说注入消息（`seen_store.get_message_id(origin_tid)` 已有链）
- 时间从正文前缀移入参数行：`[说说ID=xxx 发布于今天14:30]`

**测试**：格式断言更新（三行结构/[]括号/时间在参数行/通知含quote说明）

### Task 2: 点赞通知源C

**改动**：
- `discovery.py` 新增 `parse_like_events(text) -> list[LikeEvent]`——scope=1 响应解析，提取 `{liker}_{owner}_{hash}` key + `data-tid`/`data-uin` HTML 属性
- `wire.py` 新增 `LikeEvent` 数据类（like_key/liker_uin/liker_nickname/target_tid/target_uin/abstime）
- `client.py` 新增 `get_like_notifications(count=30)` —— scope=1 调用
- `plugin.py` `_qzone_notify_scan` 增源C：解析赞事件→去重（like_key）→构造通知 FeedItem→fav_event(LIKE)
- 通知正文：`小明 赞了你的说说「{摘要前20字}」` + quote 引用

**测试**：解析器/去重/通知构造/fav_event

### Task 3: 说说发布主动触发

**改动**：
- `plugin.py` `_qzone_poll_feeds` 首轮拉取完成后：取当前日程活动→`proactive.trigger(虚拟流, intent="你正在{活动}，想分享点什么吗？可以用 qzone_post 发一条说说")`
- `qzone_post` 保持在白名单（始终可用）
- 移除表达机会计数（无频率限制）

**测试**：触发调用链（首轮后/含日程活动/intent 文本）

### Task 4: 日程注入块增强

**改动**：
- `plugin.py` `_build_inject_blocks` 日程块：qzone=true 窗口的 activity 后追加 `(正在刷QQ空间)`

**测试**：日程块文本断言

### Task 5: 日记素材增强

**改动**：
- `plugin.py` `_generate_and_publish_diary` 素材组装增加：
  - 聊天时间线：取主程序当日消息（`ctx.message.get_recent` 或等效），按小时分段，bot 标「我:」他人标昵称，单条截 50 字
  - 真实天气：`_environment_block` 缓存或 time_aware 模块
  - 随机目标字数 150-350
- `llm_provider.py` `qzone_diary` 模板 v1→v2 重写（含聊天素材占位/天气开头/随机字数/输出卫生规则）
- `prompt_templates/catsitate_qzone_diary.prompt` 同步

**测试**：素材组装/模板版本/生成链
