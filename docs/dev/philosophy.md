# 设计哲学

> Catsitate 的一切功能决策都从这四条原则推导。理解了它们,代码里为什么这样做就不再需要解释。

## 一、拟人化优先——放弃概率行为

**核心**:bot 的行为决策(发言/入睡/关系变化/日程安排)不靠随机数或简单阈值,而是交给 LLM 判定或确定性规则——因为真人不掷骰子。

这意味着:
- **日程由 LLM 生成**:每天的作息(几点睡觉/几点刷手机/几点发说说)不是固定模板,而是 LLM 根据人设和当天情况生成的
- **入睡由 LLM 判定**:bot 晚上说「晚安」时,插件用旁路 LLM 判定这是否是真实的入睡表达(而非硬编码关键词匹配)
- **好感度由 LLM 评估**:关系变化的 delta 不是规则表(「说了谢谢+1」),而是 LLM 读完对话素材后的判断
- **衰减是确定性的**:久不联系关系会变淡(确定性时间衰减,不用 LLM 判定「要不要变淡」——一定会)

**例外**:工程护栏(冷却/限频/截断)允许用随机数,因为它们不模拟人类行为,只做资源管理。表达内容的参数(如日记篇幅)不得随机化——篇幅由配置区间指导,风格差异交给模型与温度。

## 二、工具 > 替代 LLM 做选择

**核心**:插件提供工具和护栏,LLM(planner)自主决定是否使用、怎么使用——插件绝不替 LLM 做选择。

这意味着:
- **不预判意图**:插件不会说「bot 看到好友说说了就一定会评论」——它只把说说注入上下文并提供 `qzone_comment` 工具,评论与否由 planner 自主决定
- **不替模型写内容**:评论/说说的 content 由 planner(它持有全部上下文与表达意图)直接写,插件只做润色(顺口吻,不改含义)
- **护栏是底线不是导航**:内容护栏拦掉已知违规模式,但不引导模型「应该说什么」
- **工具回执如实告知**:成功回执带回发出的内容(模型知道自己说了什么),失败回执说明原因(模型知道为什么失败),拦截回执告知命中规则(模型知道哪里出了问题)

**反面**:如果插件预判「bot 被评论了就该回复」然后自动生成回复——那就是替 LLM 做了选择,这不会出现在 Catsitate 中。

## 三、错误显式暴露——禁止静默兜底

**核心**:所有失败/异常/回退都必须有告警日志,禁止静默 fallback 掩盖问题。

这意味着:
- **回退必须告警**:润色失败回退到草稿直发 → 告警;发现层失败跳过本轮 → 告警;配置非法回退到默认 → 告警
- **不虚构数据**:天气数据缺失就省略素材行(不编造「晴」);点赞事件没有时间锚就省略时间段(不编造时间)
- **配置错误拒绝加载**:非法正则使整组护栏拒绝加载(不是跳过坏的那条);person 别名折叠校验失败直接停用模块
- **谎报失败比失败更危险**:说说已远端发布但回注失败时,回执如实报成功(谎报失败会诱导模型重复发布)

## 四、尊重本体——只改插件侧

**核心**:MaiBot 主程序(包括 prompts/、配置、.meta.toml)只读,插件侧规避主程序缺陷而不修改它。

这意味着:
- **只使用 SDK 声明的 API**:`@Tool`/`@HookHandler`/`@Command`/`call_capability`,新能力须在 `_manifest.json` 的 capabilities 列表声明
- **主程序行为在插件侧适配**:如主程序的 `is_mentioned` 消费位置在 `message_info.additional_config`(不在顶层),插件侧把键放到正确位置
- **主程序缺陷以规避或报告处理**:不在插件代码里 patch 主程序

## 从原则到实践的推导示例

| 遇到的设计问题 | 套用原则 | 得出的方案 |
|---|---|---|
| bot 应该每条评论都回吗? | 工具>替代决策 | 不预判——注入通知+提供工具,planner 自主决定回不回 |
| 润色输出可能超长,要截断吗? | 工具>替代决策 + 拟人化 | 不硬截——先带字数要求重润一次,仍超就按模型原样发(内容完整性>格式限制) |
| 发现层 API 失败了怎么办? | 错误显式暴露 | 告警后跳过本轮(下轮拉取间距自然重试,不回退放大请求的路径) |
| bot 发的说说,好友评论了要通知 bot 吗? | 拟人化优先 | 要——模拟手机推送通知的注意力模型(高频短间隔轮询三源) |
| 日记的正文应该截断吗? | 拟人化优先 + 工具>替代决策 | 不截——日记是 bot 的完整表达,长度由配置篇幅区间软约束 |
| 图片太多会占上下文,怎么处理? | 工具>替代决策 | 不丢弃——多图拼接为一张带序号角标的合成图(信息全保留,成本 O(1)) |
